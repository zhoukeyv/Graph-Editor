# Graph Editor

一个基于浏览器的交互式图编辑器，支持随机生成常见图结构、直接编辑图数据、调整节点布局，以及导出 PNG/JPG 图片。无需后端服务，打开网页即可使用。

## 功能特性

- **随机生成图**：支持随机树、链、菊花图（二叉树以外的星形结构）、二叉树、仙人掌图、二分图和普通图。
- **有向图与无向图**：普通图和二分图可以选择是否有向；不适用有向设置的结构会自动切换为无向图。
- **边权生成**：可选择有权图，并设置随机边权的最大值；也可以在编辑时为边添加、修改或清空标签。
- **文本与画布实时同步**：左侧文本框使用简单的逐行格式描述节点和边，编辑文本后会立即更新图。
- **三种操作模式**：添加模式、编辑模式和删除模式集中在右侧编辑栏。
- **节点编辑**：修改节点名称和颜色，支持固定/解除固定、拖动以及双击节点直接改名。
- **边编辑**：通过右侧编辑栏或双击边编辑边权/标签；可以新建或删除边。
- **布局工具**：对符合结构的图提供树形、仙人掌、二分图布局；符合仙人掌结构时还可以展示圆方树。
- **主题切换**：提供浅色与深色主题，并记住上次选择。
- **图片导出**：支持导出 PNG 和 JPG。
- **视图控制**：提供放大、缩小和适应画布按钮，并限制缩放范围。
- **文本撤销/重做**：在左侧数据文本框中使用 `Ctrl+Z` 撤销、`Ctrl+Y` 重做。此历史只记录文本框中的手动编辑，不记录拖动节点或其他画布操作。

## 快速开始
### 方式一：网页版快速打开

直接访问 [链接](https://zhoukeyv.github.io/Graph-Editor/) 即可。

### 方式二：直接打开

1. 下载或克隆本项目。
2. 确保 `index.html`、`script.js`、`style.css` 位于同一个目录。
3. 使用现代浏览器打开 `index.html`。

页面通过 CDN 加载 `vis-network 9.1.2`。首次打开时需要能够访问 `cdnjs.cloudflare.com`；如果网络无法访问该 CDN，图形库将无法加载。

### 方式三：通过本地 HTTP 服务打开

在项目目录中运行：

```bash
python3 -m http.server 8000
```

然后在浏览器中打开：

```text
http://localhost:8000
```

这只是一个静态网页项目，不需要安装依赖包或启动后端服务；浏览器仍需能够加载页面引用的 CDN 资源。

## 使用指南

### 1. 生成数据

在左侧「生成数据」区域设置：

| 参数 | 说明 |
| --- | --- |
| 结构类型 | 随机树、链、菊花图、二叉树、仙人掌图、二分图或普通图 |
| 节点数 `N` | 生成的节点数，生成器最多支持 300 个节点 |
| 边数 `M` | 对可自定义边数的结构设置目标边数；固定边数的结构会自动计算边数 |
| 有向图 | 控制支持有向设置的图类型 |
| 边权 | 是否为生成的边添加随机权值 |
| 最大边权 | 随机边权的上限，生成的权值从 `1` 到该值之间取值 |

不同结构有不同的边数限制。输入框下方会显示相关提示；生成器会按照对应结构的合法范围限制或调整边数。

点击「生成数据」后，左侧文本框和中间画布会同步更新。

### 2. 编辑数据文本

左侧文本框采用逐行格式：

```text
A B 10
B C
孤立节点
```

含义如下：

- `A B 10`：添加 A 与 B 之间的边，边标签为 `10`。
- `B C`：添加 B 与 C 之间的边，不设置边权/标签。
- `孤立节点`：声明一个没有关联边的节点。

每行只有一个字段时会被解析为节点；每行至少有两个字段时，前两个字段是边的两个端点，第三个及其后面的内容会合并为边标签。例如 `A B longest path` 的标签是 `longest path`。

节点名称不能包含空格。边的方向由左侧「有向图」选项决定：无向图按无向边解析，有向图按文本中的端点顺序解析。

修改文本后，图形会实时更新。点击「复制」可以复制整个文本框内容。

### 3. 使用添加、编辑和删除模式

这些按钮都在右侧「编辑栏」的「操作模式」区域。

#### 添加模式

- 单击画布空白处：创建一个节点，自动使用从 `1` 开始的第一个未被占用的数字编号。
- 依次单击两个节点：创建连接这两个节点的边。
- 有向图中的第一次点击为起点，第二次点击为终点。
- 通过画布添加的边默认没有边权/标签。

#### 编辑模式

- 单击节点或边：选择对应对象，并在右侧编辑栏中修改属性。
- 节点属性包括名称和颜色。
- 边属性包括边权/标签；将输入框清空并应用即可移除标签。
- 在普通模式下双击节点可直接改名，双击边可直接编辑边权/标签。

#### 删除模式

- 单击节点：删除该节点及其所有关联边。
- 单击边：只删除该边。

需要手动输入具体属性时，也可以直接使用右侧编辑栏中的「新建节点」和「新建边」表单。

### 4. 固定节点与调整视图

- 普通模式下单击节点可以固定或解除固定；拖动节点不会触发固定状态切换。
- 顶部工具栏可以调整节点文字大小和边长，也可以固定所有节点或解除所有节点的固定。
- 当图满足相应结构条件时，顶部会出现可用的布局按钮。
- 画布右下角的 `+`、`−` 和主页按钮分别用于放大、缩小和让整张图适应画布。
- 顶部工具栏的主题按钮用于切换浅色/深色主题。

### 5. 导出图片与撤销/重做

- 在左侧点击「导出 PNG」或「导出 JPG」即可保存当前画布图片。
- 焦点位于左侧数据文本框时，按 `Ctrl+Z` 撤销文本手动编辑，按 `Ctrl+Y` 重做；也支持 `Ctrl+Shift+Z` 重做。
- 撤销/重做仅作用于左侧文本框的手动编辑，最多保存 200 个历史步骤。通过生成数据或画布/右侧编辑栏修改而自动更新文本时，文本历史会重新建立基线。

## 技术说明

- HTML、CSS 和原生 JavaScript
- [vis-network 9.1.2](https://cdnjs.cloudflare.com/ajax/libs/vis-network/9.1.2/dist/vis-network.min.js)，通过 CDN 引入
- 使用浏览器 `localStorage` 保存主题选择
- 无需后端服务

## 注意事项

- 当前生成器将节点数限制在 300 以内。
- 树、链、菊花图和二叉树的边数由结构决定；仙人掌图、二分图和普通图的边数受各自结构约束。
- 树形、仙人掌和圆方树布局仅适用于符合对应结构要求的图。结构不符合时，对应按钮不会显示。
- 图数据保存在页面内存中；需要长期保存时，请复制左侧文本数据，或导出图片留档。
